# PetaSurya

**Atapmu, dihitung.**

Peta potensi PLTS atap tingkat bangunan untuk Indonesia. Ketik alamat, pilih atap, dapatkan kWp yang muat, kWh per tahun, penghematan rupiah, waktu balik modal, dan tCO₂e terhindar — setiap angka membawa rumus dan sumbernya.

Dua mode: **Warga/UMKM** untuk satu bangunan, **Kota** untuk agregat kelurahan sampai kota.

Cara menjalankan dan konvensi ada di [CONTRIBUTING.md](CONTRIBUTING.md).
